# Clash 节点 IP 纯净度与连通性检测工具

面向代理节点的 IP 纯净度多维风控评估与常用服务连通性测速工具。支持命令行终端即测即退，同时提供独立 Web 控制台。
想法来自ping0.cc 做这个主要目的是跳过cloudflare
---

## ✨ 核心特性

- **多维风控综合评估**：
  - **4 级 ASN 声誉库**：区分顶级云服务商（AWS/GCP/Azure 信用折扣 -2%）、标准商业 VPS (0%)、中转网络 (+2%) 与高风险主机 (+7%)。
  - **双重原生单播校验**：比对 RIR 注册归属国与实际物理落地国，结合 Anycast 广播属性，严格判定原生/广播状态。
  - **实时 DNSBL 威胁探测**：通过代理经由 Google DoH 探测 UCEPROTECT、SpamCop 等黑名单情报。
  - **网段离散扰动算法**：针对相同 ASN /24 网段应用确定性离散散列，实现幂等且拟真的风控波动。
  - **Ping0 共享人数分档**：标准 5 档预估（1-10 人、10-100 人、100-1000 人、1000-10000 人、10000+ 人），中国大陆出口自动匹配 CGNAT 特征。
- **Ping0 原生数据同步**：
  - 穿透 Clash 代理秒级解析官方 ipleak 与 JSONP 接口，获取权威 IP 类型（IDC 机房 / 家庭宽带）及精确中文地理位置。
- **常用服务并发连通测速**：
  - 通过本地代理隧道（默认 `127.0.0.1:7897`），超高并发探测 Google、YouTube、GitHub、Apple、Cloudflare、OpenAI、Bilibili 等服务，实时输出 HTTP 状态与往返延迟。
- **精确 CJK 视觉对齐**：
  - 内置字符宽度引擎，精准计算全角/半角、中英文与 Emoji 视觉单元，确保终端 ASCII 边框跨平台严丝合缝。
- **轻量独立，零常驻**：
  - 命令行执行完毕后立即退出并释放资源，无后台占用；同时内置 Windows 气泡通知与可选的 Web 控制面板。

## 🚀 使用方法

### 前置要求
- [Node.js](https://nodejs.org/) (v16+)
- 已启动的 Clash / Clash Verge 客户端（默认混合端口 `7897`）

### 1. 终端命令行检测 (CLI)
```bash
node check_cli.js
```
Windows 用户也可直接双击运行 `一键检测.bat` / `一键检测IP风控.bat`，或在 PowerShell 中运行 `.\check.ps1`。

### 2. Web UI 控制台 (可选)
```bash
# 启动 Web 服务 (默认端口 39088)
npm start
# 或运行 start.bat
```
浏览器访问 `http://127.0.0.1:39088` 查看实时可视化仪表盘。

## 📊 风控评级标准

| 评分区间 | 评级标签 | 说明 |
| :---: | :---: | :--- |
| **0% ~ 15%** | 极度纯净 | 独享原生出口，未检出扫描或滥用记录，高信誉度 |
| **16% ~ 25%** | 纯净 | 常规洁净商业机房或原生宽带，无异常黑名单标记 |
| **26% ~ 40%** | 中性 | 公用机房网络出口，适合普通网络浏览与流媒体 |
| **41% ~ 50%** | 轻微风险 | 共享代理池或并发较高，部分敏感风控平台可能出现验证码 |
| **51% ~ 70%** | 稍高风险 | 存在历史滥用或高频扫描记录，易触发风控限制 |
| **71% ~ 99%** | 极度风险 | 命中公网高危威胁黑名单或匿名暗网出口，建议更换节点 |
